# 婴儿车选购评分与多产品对比工具

请帮我开发一个完整可运行的「婴儿车选购评分与多产品对比」响应式 Web 应用。

目标用户是准备购买婴儿车的新手父母。用户可以录入多款婴儿车参数，系统按照预设的 100 分评分规则自动计算每款产品得分，并进行横向比较、排名和风险提醒。

## 一、技术要求

请优先使用：

- HTML5

- CSS3

- 原生 JavaScript

- 不依赖后端

- 不依赖数据库

- 尽量不要引入第三方框架

- 所有功能均可在浏览器本地运行

- 支持 Chrome、Edge、Safari 等现代浏览器

- PC 和移动端均需良好适配

优先实现为单页面应用。

推荐项目结构：

```text
baby-stroller-scorer/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── README.md
```

如果为了方便部署，也可以提供一个完全独立的单文件 `index.html` 版本。

要求直接双击 `index.html` 即可使用，不需要 npm、不需要构建、不需要启动服务器。

# 二、核心功能

## 1. 多产品管理

用户可以同时添加多款婴儿车进行比较。

每款产品至少包含：

- 品牌

- 型号

- 售价

- 备注

- 13 项评分参数

- 自动计算总分

- 产品标签

- 风险提醒

支持：

- 新增产品

- 编辑产品

- 删除产品

- 复制产品

- 产品重命名

- 清空全部产品

新增产品时可使用默认名称：

```text
婴儿车 1
婴儿车 2
婴儿车 3
```

用户之后可自行修改品牌和型号。

# 三、100 分评分体系

总分必须严格为：

```text
100 分
```

共 13 个评分项目。

---

## 1. 新生儿适用性

满分：

```text
18 分
```

评分规则：

| 条件                                        | 得分 |
| ------------------------------------------- | ---- |
| 官方明确 0 月+，支持完全/接近平躺或独立睡篮 | 18   |
| 官方明确 0 月+，但躺姿或新生儿支撑一般      | 14   |
| 官方要求 6 月+使用                          | 6    |
| 适用月龄不明确                              | 0    |

这是核心安全项目。

---

## 2. 执行标准 / CCC

满分：

```text
8 分
```

提供下拉选择：

### A

```text
CCC 可查 + 符合当前国内标准 + 有新版标准检测/认证依据
```

得分：

```text
8
```

### B

```text
CCC 可查 + GB 14748-2006
```

得分：

```text
7
```

### C

```text
CCC 可查，但商品详情未明确执行标准
```

得分：

```text
5
```

### D

```text
标注 GB 14748-2006，但 CCC 信息无法确认
```

得分：

```text
3
```

### E

```text
只标注 EN 1888 / ASTM 等国外标准，没有明确国内 CCC 信息
```

得分：

```text
2
```

### F

```text
只标企业标准 Q/XXX，没有明确儿童推车国标信息
```

得分：

```text
1
```

### G

```text
无明确执行标准 / 无认证信息
```

得分：

```text
0
```

页面中增加说明：

截至 2026 年 8 月：

- GB 14748-2006 仍属于现行儿童推车标准

- GB/T 14748-2025 将于 2026-11-01 实施

- GB 46516-2025 将于 2026-11-01 实施

注意：

这些日期和标准信息请集中定义在配置对象中，不要散落硬编码在 UI 中，方便未来修改。

例如：

```javascript
const STANDARD_CONFIG = {
  currentStandard: "GB 14748-2006",
  nextStandard: "GB/T 14748-2025",
  generalSafetyStandard: "GB 46516-2025",
  nextEffectiveDate: "2026-11-01"
};
```

# 八、价格功能

每款产品允许输入售价：

```text
¥
```

例如：

```text
¥3299
```

计算：

```text
每分成本 = 产品价格 ÷ 总分
```

例如：

```text
3299 ÷ 88 = ¥37.49 / 分
```

显示：

```text
每分成本：¥37.49
```

注意：

这个指标只作为辅助信息，不要直接把“价格越低”认为产品越优秀。
